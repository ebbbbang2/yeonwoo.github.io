Project Overview

건물의 전력 피크를 예측하고,
운영자의 의사결정을 지원합니다.

PeakGuard는 스마트빌딩의 전력 사용 데이터를 바탕으로 전력 피크를 사전 예측하고, 시설 관리자가 위급 임계 부하 상황을 사전에 파악하여 신속하고 체계적으로 대응할 수 있도록 지원하는 지능형 의사결정 지원 솔루션입니다.

ROOT CAUSE 01 중첩 ZIP 구조 (Nested ZIP Files)

이전 단계 ZIP 산출물이 후속 단계 작업 디렉토리에 누적 복사되어 매 스텝마다 압축 파일이 기하급수적으로 중첩 패키징되는 구조적 결함 확인.

개선 방안: ZIP 바이너리의 물리적 복사 대신 원본 파일명 및 SHA-256 해시 메타데이터 레코드로 대체하여 파이프라인 무결성을 보장.
ROOT CAUSE 02 Random Forest 크기 및 비압축 직렬화

과도한 트리 깊이와 분기 조건 수(`max_depth: 20`, `n_estimators: 200`), 그리고 기본 pickle 비압축 직렬화로 인한 원시 바이너리 팽창.

개선 방안: 결정트리 복잡도 축소(깊이 12, 리프 20) 및 joblib gzip 압축 직렬화(compress=3) 적용으로 오버헤드 제거.

Random Forest 모델 최적화 제안 (Before / After)

설정 항목 기존 설정 (Original) 개선 제안 (Proposed) 비고 / 효과
n_estimators 200 150 트리 개수 25% 축소
max_depth 20 12 과적합 방지 및 분기 노드 40% 감축
min_samples_leaf 5 20 말단 리프 노드 수 축소
max_features 1.0 0.6 특성 샘플링 최적화
저장 포맷 Uncompressed 직렬화 Compressed (joblib/gzip) 직렬화 용량 대폭 축소

트리 복잡도 축소 및 압축 직렬화 적용을 통해 성능 손실을 최소화하면서 저장 용량을 대폭 절감할 수 있는 최적화 안을 도출했습니다.

Lessons Learned

예측 정확도뿐 아니라 실제 운영 환경까지 고려합니다.

01

Model Performance

단순 지표 개선을 넘어 과적합 방지와 이상치 저항성 등 예측 모델의 실질적인 평가 지표를 검토합니다.

02

Storage Efficiency

모델 아티팩트의 저장 용량과 직렬화 압축 방식이 배포 파이프라인의 민첩성에 미치는 효율성을 살펴봅니다.

03

Pipeline Management

단계별 데이터 산출물 및 아카이빙 결과 파일의 무결성과 중복 방지 관리 구조를 체계적으로 이해합니다.

04

Dashboard UX

복잡한 시계열 AI 예측 결과를 현장 운영자가 직관적으로 이해하고 즉시 행동할 수 있는 화면으로 표현합니다.
