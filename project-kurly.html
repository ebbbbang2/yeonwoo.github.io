CASE STUDY 02 · HEALTH TECH & AGENTIC AI

복잡한 식품 원재료와 알레르기 유발 인자를
멀티에이전트로 실시간 검증합니다.

Kurly Allergy Care AX는 전자상거래 식품 상세 정보와 성분 표기를 OCR 및 LangGraph 멀티에이전트 LLM으로 파싱하여, 사용자 가족의 맞춤형 알레르기 유발 인자 및 잠재적 교차오염 위험을 실시간으로 교차 검증하는 크롬 익스텐션 기반 의사결정 지원 에이전트 서비스입니다.

ROLE
에이전트 파이프라인 & 익스텐션 UI

LangGraph 에이전틱 워크플로우 설계, FastAPI 백엔드 연동, 크롬 익스텐션 팝업/인스펙터 인터페이스 구현

DURATION & SCOPE
2024.10 — 2024.12

팀 프로젝트 (AI 에이전트 아키텍처 설계 1인, 프론트엔드 및 백엔드 연동 파이프라인 전주기 구축)

TECH STACK

Risk Level Assessment

CASE 01 · COMPUTER VISION & OCR

비정형 식품 상세 이미지 OCR 노이즈 및 포맷 왜곡

Problem

식품 상세페이지의 제품 패키지 곡면, 배경 그래디언트, 작은 글씨로 인해 OCR 오인식률 발생 (예: '대두'가 '대모'나 특수문자로 오인식).

Root Cause

원본 해상도 저하 및 이미지 압축 노이즈로 인한 텍스트 이진화(Binarization) 실패 및 경계선 번짐 현상.

Improvement Proposal

OpenCV 전처리 파이프라인(가우시안 블러, 적응형 임계처리, 대비 향상) 적용 및 형태소/자소 단위 정규화 사전 구축.

Result

알레르기 핵심 단어 인식 F1-Score 78.4% → 96.1%로 대폭 개선.

CASE 02 · SYSTEM LATENCY & UX

멀티에이전트 호출 시 브라우저 UX 병목 (Latency 지연)

Problem

LLM 순차 체인 호출 시 2.5초 이상의 응답 지연으로 실시간 쇼핑 탐색 과정에서 심각한 사용자 경험 저하 유발.

Root Cause

모든 상세 텍스트를 LLM에 일괄 프롬프트로 전송하여 토큰 지연 및 순차 처리 오버헤드 누적 발생.

Improvement Proposal

룰 베이스 사전 필터링(비동기 Fast-Path) 선행 후, 모호한 문구만 LangGraph 비동기 노드로 선별 위임하는 하이브리드 라우팅 아키텍처 구축.

Result

평균 응답 시간 2,450ms → 230ms로 약 90% 극적 단축.
